プライバシーポリシー / Privacy Policy

ことり（@kotori.family）　最終更新: 2026年10月12日

このツールについて

このツールは「ことり」の運営者が、自分の SNS アカウント（Threads・Pinterest）への投稿を準備・管理するために使う個人用のツールです。運営者以外の方が利用することはありません。

取得する情報

運営者自身のアカウントについて、投稿・ボードの作成と、投稿の反応（表示回数・いいね・コメント）の確認に必要な情報だけを、各サービスの公式 API を通じて取得します。他の利用者の個人情報を収集・販売・第三者へ提供することはありません。

保存と管理

アクセスに必要な鍵（トークン）は GitHub の暗号化された保存場所（Secrets）にのみ保管し、公開しません。連携はいつでも各サービスの設定画面から解除できます。

広告について

投稿には楽天アフィリエイトのリンクを含むことがあり、その場合は「#PR」と表示します。

English summary

This is a personal tool used only by the owner of the "kotori" account to prepare and publish posts and pins to the owner's own Threads and Pinterest accounts. It accesses only the owner's account data needed to create pins/boards and read post performance, through the official APIs. No personal data of other users is collected, sold, or shared. Access tokens are stored encrypted in GitHub Secrets. Posts may contain affiliate links, which are labeled "#PR". The connection can be revoked at any time from each service's settings.

お問い合わせ / Contact

Threads の @kotori.family へのメッセージ、または GitHub からご連絡ください。
