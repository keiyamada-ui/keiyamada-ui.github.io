🔑 合い鍵の設定

ネタ帳・推し商品・参考投稿の送信や、「今すぐ下書きを作る」「自動投稿を止める」をこの管理画面から行うための鍵です。 この端末（ブラウザ）の中だけに保存され、ネットやリポジトリには置きません。見るだけなら合い鍵はいりません。

① GitHub で合い鍵を作る（最初に1回だけ）
  1. 合い鍵を作る画面を開く
  2. Token name: kotori-dashboard
  3. Expiration: Custom → 1年後の日付（例 2027-10-10）
  4. Repository access: 「Only select repositories」→ keiyamada-ui.github.io だけを選ぶ
  5. Permissions →「Repository permissions」で次の2つを Read and write に:
    Actions・Issues（ほかは触らない）
  6. 一番下の Generate token → 表示された github_pat_ で始まる文字列をコピー
② ここに貼り付けて保存

スマホとパソコンの両方で使う場合は、それぞれで1回ずつ貼り付けてください。
合い鍵を落とした・心配なときは、GitHub の合い鍵一覧で削除すれば、すぐ使えなくなります。
