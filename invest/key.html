🔑 合い鍵

採点の結果は非公開の invest-system にあり、このページ（公開サイト）には置いていません。この端末から読むための「合い鍵」を1回だけ登録してください。合い鍵はこの端末の中だけに保存されます。

① GitHub で合い鍵を作る
  1. 合い鍵を作る画面を開く ↗
  2. Token name：invest-app
  3. Expiration：Custom → 1年後の日付
  4. Repository access：「Only select repositories」→ invest-system だけを選ぶ
  5. Permissions → Repository permissions で次の3つだけ：
    ContentsRead-onlyActionsRead and writeIssuesRead and write
    （採点結果を読む・採点を動かす・改善アイデアを送るため。ほかは触らない）
  6. 一番下の Generate token → github_pat_ で始まる文字列をコピー
② ここに貼り付けて保存

ことりの管理画面の合い鍵とは別のものです（あちらは keiyamada-ui.github.io 用）。
落とした・心配なときは GitHub の合い鍵一覧 で削除すれば、すぐ使えなくなります。
