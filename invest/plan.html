🧾 データと料金

この仕組みが使っている外部サービスと、そのプランをまとめています。プランを変える必要が出てきたら、ここから手順どおりに進めてください。料金は変わることがあるので、最終的には各サービスの公式ページで確認してください。

使っているサービス

🇯🇵 J-Quants（日本取引所グループ公式）日本株の決算・株価のデータ 使用中
Light に切り替える手順
  1. J-Quants にログインし、左のメニューの Subscription から Light を選ぶ（支払いは Billing）
  2. このアプリのホームで 「▶ 今すぐ採点する」 → プランで Light を選んで実行
  3. 次からは最新の株価で採点されます（APIキーはそのままでOK）
⚙️ GitHub Actions採点を自動で動かす場所 無料枠

非公開の場所では、自動実行に月2,000分の無料枠があります。採点は1回およそ16分なので、月に約120回まで無料です。毎日1回なら約480分で、余裕があります。

毎日1回採点した場合の目安：約24%

使いはじめる手順（最初に1回）
  1. invest-system の Secret 登録画面を開く
  2. Gemini を使うなら Name に GEMINI_API_KEY（キーは Google AI Studio）
  3. Claude を使うなら Name に ANTHROPIC_API_KEY（キーは Claude Console）
  4. 使いすぎが心配なら、Claude Console の Limits で月の上限金額を決めておく

プランを見直すサイン

  • 株価が古くて、買い時の判断に使えない → J-Quants を Light に
  • 5年分の推移（株主資本の伸びなど）で判断したい → J-Quants を Light に
  • 米国株も同じ基準で発掘したい → Financial Datasets の Credits
  • 採点が途中で止まる・遅い → まずは「実行の記録」を確認（多くは一時的なもの）
